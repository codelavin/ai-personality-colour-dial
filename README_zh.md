# AI 个性色彩盘 · Personality Colour Dial

给 AI 做「个性色彩」的分配与判定。

---

## 图 1 · 色彩盘

![色彩盘](fig1-colour-dial.svg)

基于**三原色**与其**两两调和色**构成的六边形结构：

- **三原色**对应三种性格方向：**热方向**（红）、**温和向**（绿）、**冷方向**（蓝）
- **两两调和色**对应两者之间的性格偏向，例如红与绿之间为「热偏温」
- 同一结构可直接作为产品的**设置入口标识**，以及**六边形雷达标识**使用

## 图 3 · 几何银河系

![几何银河系](fig3-temperature-galaxy.svg)

以八向悬臂呈现同一套个性色彩在**感性**与**理性**两个面上的**调温变化**。

两条彩色臂互为 180° 对望，构成两面之间的对照；其余方向以灰阶衬托，标示由内向外的层次。
